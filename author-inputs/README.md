# Research input archive for RewardFail

This branch preserves author-supplied research inputs used to inspect the public manuscript and its evidence. It does not change the English manuscript or companion archive on the main branch.

| Path | Research material |
| --- | --- |
| paper/ | Original English manuscript source, bibliography, build output and PDF |
| main-run/default/, main-run/reference/ | Original 2026-10-07 row records and pass metadata |
| main-run/report.json | Pre-correction report; not the final formal result |
| reanalysis/ | Formal 2026-10-08 report, reanalysis driver and budget-attribution records |
| results/ | Selected formal reports and original chain summaries |
| history/ | Historical code snapshots and provenance for analysis versions 9a88991 and 6c416b2 |
| research-inputs/heavy_rows.json | Byte-preserved OpenR1 answer/response selection used by the independent Linux heavy-input scenes |
| LICENSE, NOTICE, data_manifest.tsv | Existing companion licence, third-party notice and data manifest |

The original row files and retained scientific inputs are unchanged. The public corpus is incomplete: reference-pass observation/event files needed to rebuild the corrected metric are not all included here. Read reports with their recorded versions and operational definitions; a delivered manifest verifies file integrity, not scientific validity.

Upstream OpenR1 text and third-party code keep their original terms. This archive does not redistribute model weights, a full dataset, an environment, or a complete raw-log archive. MANIFEST.sha256 lists the files in this research snapshot, excluding itself. Read SANITIZATION.md for the limitations of the supplied redacted copies.
